# Changelog

All notable additions to the Kafka Guide are recorded here. Newest entries first.
Format: date, area, what changed, and why (usually a reader request).

## 2026-09-07 – Initial release (v1.0)

- Created the guide structure: fundamentals, developer, admin, architect, question bank, reference, diagrams.
- Added `STYLE-GUIDE.md` so all future chapters stay consistent.
- Added role-based learning roadmaps for Architect, Admin and Developer.
- Added the diagram catalogue (`diagrams/`) with PlantUML sources and a render script.
- Added question banks: fundamentals, developer, admin, architect, scenarios, coding exercises.
- Added reference sheets: CLI, configuration, metrics and alerts, glossary and KIPs, versions and roadmap.

## How to request additions

Open an issue or ask in the session with: the topic, the role it is for, and whether you want a chapter,
questions, a diagram, or a runbook. Every accepted request lands here with its date.
